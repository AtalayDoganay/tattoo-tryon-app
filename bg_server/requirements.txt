# Direct runtime dependencies, pinned.
#
# Pinning matters here for two reasons: a Railway rebuild must produce the same
# image as the one that was tested, and an unpinned transitive bump is how a
# compromised release reaches production unnoticed. Review and bump these
# deliberately (Dependabot opens weekly PRs for them).
#
# Version ranges below were checked against rembg 2.0.77's own constraints:
#   numpy>=2.3,<3 | pillow>=12.1,<13 | scikit-image>=0.26,<0.27 | onnxruntime>=1.23.2

# --- web stack ---------------------------------------------------------------
flask==3.1.3
# 6.x fixes the permissive-origin and regex CVEs present in flask-cors < 5.

# Shared rate-limit backend. Required in production: the in-memory default is
# per-worker and does not limit anything across Gunicorn workers.

# Production WSGI server. Flask's dev server is never used in the container.
gunicorn==26.0.0
